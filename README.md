# Operating Systems Lab Assignment 1

Implementation and comparison of fundamental CPU scheduling algorithms in Python.

## Overview
This lab demonstrates process scheduling using FCFS and SJF, including completion time, turnaround time, waiting time, averages, and simple Gantt-chart output.

## Topics
- Process management
- FCFS scheduling
- SJF scheduling
- Waiting time and turnaround time
- Gantt charts
- Scheduling comparison

## Tech Stack
Python

## Purpose
Academic operating-systems practice with executable scheduling simulations.
